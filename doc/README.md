# Dokumentasi KanzaBridge

Folder ini berisi dokumentasi teknis untuk instalasi, migrasi database, dan seeding aplikasi **KanzaBridge** (CodeIgniter 4).

## Daftar Dokumentasi

| File | Deskripsi |
| ---- | --------- |
| [installation.md](installation.md) | Instalasi lengkap: prasyarat, konfigurasi, migration, seed, dan menjalankan server |
| [migration.md](migration.md) | Detail migrasi database: tabel, relasi, dan perintah Spark |
| [seeding.md](seeding.md) | Detail seeding: role default dan perintah `db:seed` |

## Tujuan

- Menyediakan panduan instalasi yang konsisten untuk developer baru
- Mendokumentasikan skema database dan cara migrasinya
- Menjelaskan proses seeding data awal

---

**Status:** Production Ready  
**Framework:** CodeIgniter 4  
**Database:** MySQL 5.7+
